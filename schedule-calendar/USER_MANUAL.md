## はじめに

### スケジュールカレンダーとは？

スケジュールカレンダーは、ブラウザ上で動作するシンプルなスケジュール管理アプリです。予定の追加・削除、月次カレンダー表示など、日々のスケジュール管理に必要な基本機能を備えています。

### 主な機能

✅ **月次カレンダー表示**  
見やすいカレンダー形式で予定を確認できます

✅ **スケジュール追加**  
日付、時刻、タイトル、詳細を入力して予定を登録できます

✅ **スケジュール削除**  
不要になった予定を簡単に削除できます

✅ **自動保存**  
予定は自動的に保存され、次回起動時も表示されます

✅ **今日の日付ハイライト**  
今日の日付が青色で強調表示されます

✅ **予定インジケーター**  
予定がある日付には黄色のマークが表示されます

## アプリの起動方法

### 方法1: ブラウザで直接開く

1. ファイルマネージャーで `schedule-calendar` フォルダを開く
2. `index.html` ファイルをダブルクリック
3. ブラウザが起動し、アプリが表示されます

### 方法2: ローカルサーバーを使用（推奨）

```bash
# ターミナルで以下のコマンドを実行
cd schedule-calendar
python3 -m http.server 8080
```

その後、ブラウザで以下のURLにアクセス：
```
http://localhost:8080
```

### 対応ブラウザ

- Google Chrome（推奨）
- Mozilla Firefox
- Microsoft Edge
- Safari
- Opera

※ Internet Explorerには対応していません

## 基本的な使い方

### 1. カレンダーを見る

#### 今月のカレンダーを見る

アプリを起動すると、自動的に今月のカレンダーが表示されます。

#### 前の月を見る

1. カレンダー上部の **「前月」** ボタンをクリック
2. 1ヶ月前のカレンダーが表示されます
3. 何度でもクリックして過去の月を見ることができます

#### 次の月を見る

1. カレンダー上部の **「次月」** ボタンをクリック
2. 1ヶ月後のカレンダーが表示されます
3. 何度でもクリックして未来の月を見ることができます

---

### 2. 予定を追加する

#### 基本的な追加方法

1. **日付を選択**
   - カレンダーの日付をクリック、または
   - 「日付」欄に直接入力

2. **時刻を入力**
   - 「時間」欄をクリック
   - 時刻を選択（例: 14:30）

3. **タイトルを入力**
   - 「タイトル」欄をクリック
   - 予定の名前を入力（例: ミーティング）

4. **詳細を入力（オプション）**
   - 「詳細」欄をクリック
   - 予定の詳しい内容を入力（例: プロジェクトの進捗確認）
   - ※ 詳細は省略可能です

5. **追加ボタンをクリック**
   - 「追加」ボタンをクリック
   - 「スケジュールを追加しました！」というメッセージが表示されます
   - カレンダーと予定一覧に反映されます

#### 入力例

```
日付: 2025-10-26
時間: 14:30
タイトル: ミーティング
詳細: プロジェクトの進捗確認
```

#### 注意事項

⚠️ **必須項目**
- 日付、時間、タイトルは必ず入力してください
- 詳細は省略できます

⚠️ **入力形式**
- 日付: YYYY-MM-DD形式（例: 2025-10-26）
- 時刻: HH:MM形式（例: 14:30）

---

### 3. 予定を確認する

#### カレンダーで確認

- 予定がある日付には **黄色の背景** と **小さな丸いマーク** が表示されます
- 日付をクリックすると、その日付が入力フォームに自動入力されます

#### 予定一覧で確認

- 画面下部の「スケジュール一覧」に全ての予定が表示されます
- 予定は **日時順（古い順）** に並んでいます
- 各予定には以下の情報が表示されます：
  - タイトル
  - 日付と時刻（曜日付き）
  - 詳細説明（入力した場合）

---

### 4. 予定を削除する

#### 削除方法

1. 「スケジュール一覧」から削除したい予定を探す
2. 予定カードの右上にある **「削除」** ボタンをクリック
3. 予定が即座に削除されます
4. カレンダーと予定一覧から消えます

#### 注意事項

⚠️ **削除の取り消しはできません**
- 一度削除した予定は元に戻せません
- 削除する前に、本当に削除してよいか確認してください

## 便利な機能

### カレンダーから日付を選択

予定を追加する際、カレンダーの日付をクリックすると、その日付が自動的に入力フォームに入力されます。

**使い方:**
1. カレンダーで予定を追加したい日付をクリック
2. 「日付」欄に自動的に日付が入力されます
3. 時刻とタイトルを入力して「追加」をクリック

### 今日の日付を確認

今日の日付は **青色** で表示されるため、一目で分かります。

### 複数の予定を追加

同じ日に複数の予定を追加できます。予定一覧には時刻順に表示されます。

**例:**
```
2025年10月26日(日) 09:00 - 朝のミーティング
2025年10月26日(日) 14:00 - プロジェクト会議
2025年10月26日(日) 18:00 - 夕食の予定
```

### 過去の予定も管理

過去の月に移動して、過去の予定を確認・追加・削除できます。

## よくある質問

### Q1. 予定はどこに保存されますか？

**A:** 予定はブラウザのLocalStorage（ローカルストレージ）に保存されます。インターネット接続は不要で、同じブラウザで開けば予定が表示されます。

### Q2. 他のパソコンやスマートフォンで予定を見られますか？

**A:** いいえ、予定は使用しているブラウザにのみ保存されます。他のデバイスでは表示されません。

### Q3. ブラウザを閉じても予定は残りますか？

**A:** はい、予定は自動的に保存されるため、ブラウザを閉じても次回起動時に表示されます。

### Q4. 予定を編集できますか？

**A:** 現在のバージョンでは編集機能はありません。予定を変更したい場合は、一度削除してから新しく追加してください。

### Q5. 何件まで予定を登録できますか？

**A:** ブラウザのLocalStorageの容量（通常5-10MB）まで登録できます。一般的な使用では数千件以上登録可能です。

### Q6. 予定の時刻を過ぎたら自動的に削除されますか？

**A:** いいえ、自動削除機能はありません。不要になった予定は手動で削除してください。

### Q7. 予定にアラームやリマインダーを設定できますか？

**A:** 現在のバージョンでは通知機能はありません。

### Q8. 週表示や日表示はできますか？

**A:** 現在のバージョンでは月表示のみです。

### Q9. 予定をカテゴリー分けできますか？

**A:** 現在のバージョンではカテゴリー機能はありません。タイトルに「[仕事]」「[プライベート]」などを付けて区別することをお勧めします。

### Q10. 予定をエクスポート（出力）できますか？

**A:** 現在のバージョンではエクスポート機能はありません。

## トラブルシューティング

### 予定が保存されない

#### 原因1: プライベートブラウジングモード
- **対処法**: 通常モードでブラウザを開いてください

#### 原因2: ブラウザの設定でLocalStorageが無効
- **対処法**: ブラウザの設定で「Cookie」や「サイトデータ」を有効にしてください

#### 原因3: ストレージ容量が満杯
- **対処法**: ブラウザのキャッシュをクリアしてください

### カレンダーが表示されない

#### 原因: JavaScriptが無効
- **対処法**: ブラウザの設定でJavaScriptを有効にしてください

### スタイルが崩れている

#### 原因: CSSファイルが読み込まれていない
- **対処法**: 
  1. ブラウザを再読み込み（F5キー）
  2. キャッシュをクリアして再読み込み（Ctrl+F5）

### 予定が突然消えた

#### 原因1: ブラウザのデータをクリアした
- **対処法**: 残念ながら復元できません。今後は定期的にバックアップを取ることをお勧めします

#### 原因2: 別のブラウザで開いた
- **対処法**: 予定を登録したブラウザで開いてください

### 日付や時刻が入力できない

#### 原因: ブラウザが古い
- **対処法**: ブラウザを最新バージョンにアップデートしてください

## データのバックアップ方法

予定を失わないために、定期的にバックアップを取ることをお勧めします。

### バックアップ手順

1. ブラウザで開発者ツールを開く
   - Windows/Linux: F12キー
   - Mac: Command + Option + I

2. 「コンソール」タブをクリック

3. 以下のコマンドを入力してEnterキーを押す
   ```javascript
   console.log(localStorage.getItem('schedules'));
   ```

4. 表示されたテキストをコピーして、テキストファイルに保存

### 復元手順

1. ブラウザで開発者ツールを開く

2. 「コンソール」タブをクリック

3. 以下のコマンドを入力（`[保存したデータ]`の部分にバックアップしたテキストを貼り付け）
   ```javascript
   localStorage.setItem('schedules', '[保存したデータ]');
   ```

4. ページを再読み込み

## 使い方のコツ

### 📌 コツ1: タイトルは短く分かりやすく

予定一覧で見やすくするため、タイトルは簡潔にしましょう。

**良い例:**
- ミーティング
- 歯医者
- 買い物

**悪い例:**
- 午後2時から会議室Aで行われる部署のミーティング

### 📌 コツ2: 詳細欄を活用

詳しい情報は詳細欄に書きましょう。

**例:**
```
タイトル: ミーティング
詳細: 会議室A、参加者：田中さん、佐藤さん、議題：来月の計画
```

### 📌 コツ3: カテゴリーをタイトルに含める

カテゴリー機能がないため、タイトルに記号を付けて分類しましょう。

**例:**
- [仕事] ミーティング
- [プライベート] 歯医者
- [買い物] スーパー

### 📌 コツ4: 定期的に古い予定を削除

過去の予定が溜まると見づらくなるため、定期的に削除しましょう。

### 📌 コツ5: 時刻は余裕を持って設定

移動時間などを考慮して、少し早めの時刻を設定すると良いでしょう。
